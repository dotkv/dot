Usage

Read, write, update, and expire typed values.

Typed values

Set, Get, and Update support []byte, string, int64, uint64, float64, and bool. Each record stores its value type. Set may replace an existing key with a different type; Get[T] and Update[T] require the stored type and return an error wrapping ErrTypeMismatch otherwise. Use errors.Is to check it. There are no implicit conversions: string and []byte are distinct types, as are the numeric types. Get returns ErrNotFound for missing or expired keys before checking the type; Update treats those keys as absent. A mismatched update leaves the value unchanged without invoking its callback.

err := db.Set("counter", uint64(42))
value, err := db.Get[uint64]("counter")
_, err = db.Get[int64]("counter") // errors.Is(err, dot.ErrTypeMismatch)

Keys accept []byte or string. Unlike values, the key's Go type does not affect identity: "a" and []byte("a") address the same record.

Delete and handle errors

Deleting a missing key succeeds. Use errors.Is to distinguish a miss from a type mismatch or an I/O error:

if err := db.Delete("greeting"); err != nil {
    return err
}
value, err := db.Get[string]("greeting")
switch {
case errors.Is(err, dot.ErrNotFound):
    fmt.Println("missing or expired")
case err != nil:
    return err
default:
    fmt.Println(value)
}
ErrorMeaning
ErrNotFoundA requested key is missing or expired.
ErrTypeMismatchGet or Update requested a different type from the stored value.
ErrDatabaseLockedAnother Open holds the lock for this database path.
ErrMigrationRequiredThe on-disk layout is incompatible with the requested layout or this implementation.
ErrInvalidValueA record type or value encoding is invalid.
os.ErrClosedAn operation was attempted after the database closed.

Expiration and sync

Expiration is an absolute time.Time, not a relative TTL. Compute a deadline when writing the key:

err := db.Set("session", "active",
    dot.WithExpiration(time.Now().Add(15*time.Minute)),
    dot.WithSync(true),
)

Expired keys read as missing before background cleanup reclaims their space. An expiration passed to Open is a shared absolute deadline, not a new duration for every write. Set uses the database default unless overridden. Update keeps an existing key's expiration unless explicitly overridden; an insert uses the database default. Clear an expiration with dot.WithExpiration(time.Time{}).

Per-call WithSync overrides the database setting, including WithSync(false) on a database opened with synchronous writes.

Atomic updates

Update atomically reads the current value, calls the callback, and stores the callback's result, inserting when the key is missing:

err := db.Update("counter", func(cur uint64, _ bool) (uint64, error) {
	return cur + 1, nil
})

The callback receives the current value and true, or the zero value and false for a missing or expired key. Returning a non-nil error aborts the write and propagates the error; the returned value is ignored. To update only existing keys, return ErrNotFound (or any error) when exists is false:

err = db.Update([]byte("message"), func(cur []byte, exists bool) ([]byte, error) {
	if !exists {
		return nil, dot.ErrNotFound
	}
	return append(cur, '!'), nil
})

Update supports the same value types as Get and Set. A type mismatch or malformed encoding fails before the callback runs. WithExpiration sets the expiration of the written record; otherwise an existing key keeps its expiration and an insert uses the database default. Unchanged encodings with an unchanged expiration skip the log append. Returning nil bytes with a nil error stores an empty value.

The callback runs once under an exclusive shard lock. Keep it short and do not call methods on the same database from it. Byte slices passed to the callback are owned by the caller and may be mutated or retained; returned bytes are copied into the log. A panic leaves the stored value unchanged and releases the lock. A failed write cannot undo external effects performed by the callback.

Scan

Scan iterates over every live key/value pair with a range-over-func iterator:

for k, v := range db.Scan() {
	fmt.Printf("%s=%x\n", k, v)
}

Pairs are yielded in shard order; order is otherwise unspecified, and the scan is not a point-in-time snapshot. Each shard's read lock is held while that shard is scanned. Expired entries are skipped. The yielded slices are reused across iterations; copy them to retain.

Scan returns raw encoded value payloads. It does not perform the typed decoding of Get[T]: numbers are eight little-endian bytes and boolean payloads are empty. Use typed reads when the logical value is needed. See the record format for the encodings.
