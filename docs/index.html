Getting started

A small, on-disk key-value store embedded in your Go application.

Dot adds persistent typed values, atomic updates, and expiration to your Go application, with background cleanup and an optional metrics dashboard.

Open a database

Add Dot using the Go toolchain required by go.mod:

go get github.com/dotkv/dot
package main

import (
	"fmt"
	"log"

	"github.com/dotkv/dot"
)

func main() {
	db, err := dot.Open("data")
	if err != nil {
		log.Fatal(err)
	}
	defer db.Close()

	if err := db.Set("greeting", "hello"); err != nil {
		log.Fatal(err)
	}
	greeting, err := db.Get[string]("greeting")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(greeting) // hello
}

Open creates a missing directory or reopens an existing database. Share one *dot.DB across goroutines; a database path can only be opened once at a time. Close releases resources and keeps the data. Destroy closes the database and removes its directory.

Configure writes

Options passed to Open set defaults. Write options can also be set on individual Set, Update, and Delete calls:

db, err := dot.Open("data", dot.WithSync(true))
OptionDefaultUse
WithSync(enabled)falseSync changed writes before returning.
WithExpiration(time)No expirationSet a fixed deadline for Set and Update; a zero time clears it.
WithShardCount(count)64Choose a new database's shard count: a power of two from 1 to 1024.
WithCompactionThreshold(ratio, bytes)0.33, 1 MiBAdjust background cleanup thresholds per shard.

Start with the defaults, then choose WithSync(true) if each write must reach storage before returning. See storage and recovery for durability and cleanup, usage for values and atomic updates, and metrics for the embedded dashboard.
