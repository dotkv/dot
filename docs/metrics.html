Metrics dashboard

Inspect storage, throughput, and latency from an embedded dashboard.

Mount the handler

Mount the embedded dashboard in your application's HTTP server:

mux := http.NewServeMux()
mux.Handle("/debug/dot/", http.StripPrefix("/debug/dot",
    db.MetricsHandler()))
if err := http.ListenAndServe("127.0.0.1:8080", mux); err != nil {
    log.Print(err)
}

Open http://127.0.0.1:8080/debug/dot/. Register the path with a trailing slash and strip the prefix without that slash, as shown above. Authentication and HTTP server shutdown belong to your application.

Configure collection

By default, db.MetricsHandler() collects only while viewers are connected and keeps live history in the browser until reload. Pass options to retain persistent history across restarts, change the live snapshot interval, or disable latency timing:

handler := db.MetricsHandler(
    dot.WithMetricsHistory(7*24*time.Hour),
    dot.WithMetricsInterval(250*time.Millisecond),
    dot.WithMetricsLatency(false),
)
OptionDefaultUse
WithMetricsHistory(duration)0 (disabled)Retain one-second snapshots in METRICS across restarts (about 21.1 MiB per day).
WithMetricsInterval(interval)time.SecondSet the live WebSocket snapshot interval (must be positive).
WithMetricsLatency(enabled)trueRecord operation latency in addition to throughput counts.

When positive history retention is enabled (rounded up to whole seconds), collection starts when the handler is constructed and runs until db.Close(), even without connected viewers. Multiple history-enabled handlers on the same database must use the same retention; changing retention on reopen resizes the METRICS ring and keeps samples that fit. Latency timing stays active while any connected viewer or history collector requests it.

Storage metrics

MetricMeaning
On-disk sizeAllocated filesystem space under the database path, including metadata and temporary cleanup files, excluding the METRICS history file.
Obsolete bytesRetained history that cleanup can reclaim.
EntriesIndexed keys, including expired keys awaiting cleanup.
Index mmapMapped index space, including pages not resident in RAM.

Storage readings can lag while a shard is busy. Failed disk scans retain the previous reading and mark it stale. Totals appear after the first complete sample; they are not a point-in-time snapshot.

Operation metrics

The table shows Get, Set, Delete, and Update throughput, mean latency, and approximate p99 over a trailing ten-second window. Initial readings use a shorter window. All calls count, including misses and errors; latency includes lock waits, update callbacks, and syncs. P99 rounds up by at most 12.5% and is less useful with few samples. Empty windows show zero throughput and unavailable latency.

Select table values or metric buttons to graph them. Multiple series can share a graph when their units match; selecting a different unit replaces the selection. The Y-axis covers all loaded samples for the selected metrics, keeping its scale stable while scrolling. It adjusts when the loaded data or selection changes. Hover for exact sample values.

Persistent history

Choose a one-minute, one-hour, one-day, seven-day, or 30-day window, or all retained samples. The graph follows new samples by default. Scroll or drag the graph, or use the scrubber below it (including arrow keys, Page Up, Page Down, Home, and End), to inspect older readings. Moving back to the latest end resumes following new samples.

The browser loads only the requested range, keeping at most 20,000 samples and preserving each selected series' minima and maxima in wide views. Restart or crash gaps longer than three seconds break the line rather than interpolating across outages.

The METRICS file stores one snapshot per second in a fixed-size ring (approximately 21.1 MiB per retained day) and is excluded from the on-disk database size shown in the dashboard. History writes run in the background and sync every minute and on db.Close(); torn or corrupt records are skipped, and history errors appear in the dashboard without affecting database operations.
