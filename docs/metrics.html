Metrics dashboard

Inspect storage, throughput, and latency from an embedded dashboard.

Mount the handler

Mount the embedded dashboard in your application's HTTP server:

mux := http.NewServeMux()
mux.Handle("/debug/dot/", http.StripPrefix("/debug/dot", db.MetricsHandler()))
if err := http.ListenAndServe("127.0.0.1:8080", mux); err != nil {
    log.Print(err)
}

Open http://127.0.0.1:8080/debug/dot/. Register the path with a trailing slash and strip the prefix without that slash, as shown above. Authentication and HTTP server shutdown belong to your application.

Configure collection

The dashboard receives a snapshot every second while viewers are connected. Set a different positive interval or disable latency timing:

handler := db.MetricsHandler(
    dot.WithMetricsInterval(250*time.Millisecond),
    dot.WithMetricsLatency(false),
)

Disabling latency keeps throughput counts. Timing remains active if another connected handler needs it. Collection stops when viewers disconnect; db.Close() closes the streams.

Storage metrics

MetricMeaning
On-disk sizeAllocated filesystem space under the database path, including metadata and temporary cleanup files.
Obsolete bytesRetained history that cleanup can reclaim.
EntriesIndexed keys, including expired keys awaiting cleanup.
Index mmapMapped index space, including pages not resident in RAM.

Storage readings can lag while a shard is busy. Failed disk scans retain the previous reading and mark it stale. Totals appear after the first complete sample; they are not a point-in-time snapshot.

Operation metrics

The table shows Get, Set, Delete, and Update throughput, mean latency, and approximate p99 over a trailing ten-second window. Initial readings use a shorter window. All calls count, including misses and errors; latency includes lock waits, update callbacks, and syncs. P99 rounds up by at most 12.5% and is less useful with few samples. Empty windows show zero throughput and unavailable latency.

Select table values or metric buttons to graph them. Multiple series can share a graph when their units match; selecting a different unit replaces the selection. Hover for exact sample values.

Browser history

Choose the last minute, last hour, or all retained samples. Each browser keeps up to 20,000 snapshots, about 5.5 hours at the default interval. Reloading clears the graph history; disconnecting the last viewer also resets the operation window.
